# AI-Augmented Analytics for Data Visualization: Module 3: Categorical Data

Prompts are on the course page.

## Installation

1. Download and unzip this project, or clone this repository.
2. Install R and Quarto. Open the `.Rproj` file in RStudio, or open the folder in Positron.
3. Run `source("setup.R")` once in the R console.
4. Open `notebooks/03_categorical.qmd` and use the prompt from the module guide.
5. Render the completed notebook with `quarto render notebooks/03_categorical.qmd` from the project folder.

## Contents

- `notebooks/03_categorical.qmd`: the module task.
- `inputs/raw/census_state_race_ethnicity_long.csv` and its codebook in `inputs/raw/codebooks/`.
- `setup.R`: required R packages.
- `_quarto.yml`: notebook rendering settings.
